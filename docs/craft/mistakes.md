# Mistakes — what makes a set sound wrong

The brain runs this list against its own plan before returning it; the conductor refuses what is
`enforced`; the set log catches the rest.

| Mistake | Why it hurts | Rule | Status |
|---|---|---|---|
| **key clash** — two tonal layers or two tracks in unrelated keys at once | dissonance with no intent | only same / ±1 / relative / bridged | enforced |
| **double bass** — two subs sounding together | mud, pumping, a smaller sound | one `sub` at a time; bass swap on the phrase | enforced |
| **mixing off the phrase** | the listener feels a stumble even when the keys match | structural changes on 8-bar boundaries; handovers on 16 | enforced |
| **tempo jump** | the body notices before the ear | ≤ 4 BPM per track, or a bridge | enforced |
| **no breathing** — drop after drop | fatigue; the third drop is smaller than the first | a break after two drops | enforced |
| **everything at once** | no contrast, no hierarchy | add one thing per 4 bars in a build | advised |
| **a build without a drop** | a broken promise (once is a trick; twice is a fault) | at most one fake-out per set | advised |
| **the same transition every time** | the seams become audible | no repeat of a non-bass-swap transition back to back | enforced |
| **a break that does not resolve** | tension with no payoff | a higher-energy section within 32 bars of a break | enforced |
| **the lead over the wrong chord** | wrong note, obviously | melody notes in the section's key unless chromatic and resolving | enforced (validate warning → the generator avoids it) |
| **stereo low end** | cancels on a club system | mono below 120 Hz | enforced |
| **crushed dynamics** | loud and lifeless | headroom −6 dBFS; crest factor watched | enforced (headroom); advised (crest) |
| **ignoring the prompt** | the person asked for less energy and got more | a live prompt lands within 2 phrases and the log shows it | enforced (P5) |
| **a rework that loses the melody** | the person no longer recognises the song | the melody's contour survives the arrangement (bet B05) | advised |
