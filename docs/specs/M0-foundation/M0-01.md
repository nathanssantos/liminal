## Context

`/dev/liminal` holds only documents. It must become a git repo, a public repo at
`nathanssantos/liminal`, and a pnpm + Turborepo monorepo with the TypeScript, lint and test base
the packages will inherit.

## What to do

- `gh auth switch -u nathanssantos`; `git init`; `gh repo create nathanssantos/liminal --public`
  with a one-line description; `main` as default branch.
- Root `package.json` with `packageManager: pnpm@11.x`, `engines.node: 24.x`, scripts `check`,
  `lint`, `typecheck`, `test`, `dev`; `pnpm-workspace.yaml` with `apps/*`, `packages/*`.
- `turbo.json` with `lint`, `typecheck`, `test`, `build`, `dev`.
- `tsconfig.base.json`: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`,
  `verbatimModuleSyntax`, `module: NodeNext`, `target: ES2023`.
- `biome.json` at the root; `.nvmrc` = 24; `.editorconfig`; `.gitignore` (node, python,
  `.claude/local-state.json`, `CLAUDE.local.md`, `dist*`; `evidence/` is versioned — small
  files, they are the proof); `LICENSE` MIT; `README.md` already exists.
- First commit: `chore: bootstrap the monorepo`.

## Done when

- [ ] `git remote -v` points to `github.com/nathanssantos/liminal` and the repo is public — proof: command output and `gh repo view`.
- [ ] `pnpm install` runs clean on a fresh checkout — proof: full output, exit 0.
- [ ] `pnpm check` exists and runs Biome + tsc + Vitest at the root, **without truncating output** — proof: output with counts.
- [ ] `.claude/agents/` and `.claude/skills/` are versioned; `.claude/local-state.json` and `CLAUDE.local.md` are not — proof: `git check-ignore`.

## Out of scope

Packages (M0-02), CI (M0-04), board (M0-05).

## Risks and questions

- Exact Turborepo and Biome versions: the latest stable on the day. Record in `measurements.md`.
