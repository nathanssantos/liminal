## Context

The loop only merges on green CI. CI must run everything `pnpm check` runs, plus the headless
engine in Node (which does not exist yet, but the job is born now) and Playwright with Electron.

## What to do

- `.github/workflows/ci.yml`: job `node` (ubuntu): pnpm with cache, `pnpm check`; job `python`
  (ubuntu): `uv sync`, ruff, mypy, pytest; job `desktop` (macos): `pnpm --filter desktop test:e2e`
  (Playwright with Electron; in M0 it is only "the window opens").
- No job with `continue-on-error`. No `| tail`.
- `.github/pull_request_template.md` with the three sections of the process (§3.5).
- Badge in `README.md`.

## Done when

- [ ] the three jobs pass on `main` — proof: link to the green run.
- [ ] a PR with a deliberately broken test turns **red** and does not merge — proof: link to the red run (the PR is closed without merge).
- [ ] the PR template appears when opening a PR — proof: screenshot.

## Out of scope

Branch protection (M0-09). Artifact publishing.

## Risks and questions

- The macOS runner is slower and costs more minutes; the `desktop` job only runs when
  `apps/desktop`, `packages/engine` or `packages/protocol` change (`paths`).
