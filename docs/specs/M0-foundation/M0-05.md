## Context

The board is the loop's queue (process §2). It must exist with the right fields before any card,
and the `gh` token needs the Projects scope.

## What to do

- `gh auth refresh -s project,read:project` on the `nathanssantos` account.
- `gh project create --owner nathanssantos --title liminal`; fields: **Status** with the eight
  columns of the process (`Backlog`, `Specified`, `Ready`, `In progress`, `In review`, `Blocked`,
  `Decision needed`, `Done`), **Priority** (P0–P3), **Listening** (checkbox). Link to the repo.
  Board view: kanban by Status, with `Blocked` and `Decision needed` placed first so they are seen.
- Milestones `M0 · Foundation` … `M5 · Booth`, with the plan's one-line description.
- Labels: `area:score`, `area:composition`, `area:engine`, `area:analysis`, `area:brain`,
  `area:conductor`, `area:protocol`, `area:desktop`, `area:analyzer`, `area:infra`, `area:docs`,
  `spike`, `question`, `decision`, `idea`, `research`, `milestone`, `release`.
- `.github/ISSUE_TEMPLATE/card.md` with the mandatory sections and the note "the source is the
  `.md` in `docs/specs`; edit there or here — the sync reconciles".
- Record nothing by id: the board scripts resolve the project, fields and options by name
  ([board.md](../cross-cutting/board.md)).
