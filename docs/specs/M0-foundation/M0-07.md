## Context

The loop's skills live **in this repo** (`.claude/skills/`: `liminal`, `queue`, `start`,
`review`, `deliver`, `spec`) and call the `tools/board` modules. Each module's contract is in
[board.md](../cross-cutting/board.md). No token, no config: authenticated `gh`, repo from the
`git remote`, project by title.

## What to do

- `board.queue`, `board.open`, `board.move`, `board.comment`, `board.check`, `board.deliver` per
  the contract (`board.sync` is M0-06).
- Watermark in `.claude/local-state.json` (gitignored) for the `inbox`.
- `board.deliver --gates-only` runs `pnpm check` with Biome on `--error-on-warnings`, saves the
  full output to `evidence/_gates/<date>.log` and cites the path.
- JSON fixtures with `gh` responses for every module; tests without network.
- Minimal `CLAUDE.local.md` (not versioned): "Current situation" only.

## Done when

- [ ] `/queue` returns inbox, PRs, ordered `board.ready` and `cardsToMove` — proof: real output against the board.
- [ ] `/start #<an M1 card>` returns `CLEARED` or `CHECK` with the card, the area's memory and `repoAlreadyHas` — proof: output.
- [ ] `board.open` on a card with an open `depends_on` returns `BLOCKED` with the barrier named — proof: fixture test.
- [ ] `board.move` refuses to demote a Status with `statusBy: human` — proof: test.
- [ ] `board.move <nº> "Blocked"` without `--reason` is refused; with it, the comment is posted and `--unblock` returns the card to `sync.previousStatus` — proof: tests.
- [ ] `board.deliver --stale-docs` flags a backticked path that does not exist and a command missing from `package.json` — proof: two tests.
- [ ] `board.deliver --gates-only` blocks on a planted comment in the diff and on a lint warning — proof: two tests + a real run.
- [ ] `board.deliver --rebase-only` aborts when the commit count changes — proof: test with a temporary repo.
- [ ] no module writes a token — proof: `grep -ri token tools/board` only in `gh` error names.
- [ ] `ruff`, `mypy --strict`, `pytest` green in `tools/board` — proof: output.
